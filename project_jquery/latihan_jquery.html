1. append() dan remove()

Fungsi append() dipakai untuk menambahkan elemen baru ke dalam elemen yang sudah ada, sedangkan remove() dipakai untuk menghapus elemen. Di sini dipakai untuk menambah tugas ke dalam daftar, dan klik tombol Hapus untuk menghapusnya.

    2. val() dan keyup()

    Fungsi val() dipakai untuk mengambil isi dari input, sedangkan keyup() berjalan setiap kali tombol keyboard dilepas. Di sini dipakai untuk menghitung jumlah karakter yang diketik.

    Jumlah karakter: 0

    3. hover()

    Fungsi hover() menjalankan aksi saat kursor masuk dan keluar dari sebuah elemen. Di sini warna dan teks kotak berubah ketika kursor diarahkan ke atasnya.

    Arahkan kursor ke sini

    4. attr()

    Fungsi attr() dipakai untuk mengambil atau mengubah atribut elemen HTML. Di sini dipakai untuk mengganti alamat tujuan (href) dari sebuah link.
